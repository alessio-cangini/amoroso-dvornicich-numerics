# Another lower bound for the height in abelian extensions

This repository contains the Wolfram Mathematica notebook `computations.nb`, 
which provides the numerical computations supporting Chapter 4 of the thesis.


## Overview

The notebook investigates lower bound for the logarithmic absolute Weil height 
in abelian extensions of the rationals using auxiliary functions associated 
with certain suitable homogeneous polynomials.

The computations involve symbolic differentiation and numerical optimization.

## Requirements

Wolfram Mathematica (the notebook was created using version 14.3)

No external packages or datasets are required.
